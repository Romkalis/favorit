Клиентское приложение для поиска автозапчастей и складских предложений по артикулу.

## Стек и версии

Версии ниже соответствуют установленным зависимостям проекта:

| Библиотека | Версия |
| --- | --- |
| React | 19.3.1 | 
| React DOM | 19.3.1 |
| Redux Toolkit | 2.13.0 |
| React Redux | 9.3.0 |
| Zod | 4.6.7 |
| Vite | 8.3.5 |
| ESLint | 10.13.0 |

## Запуск

Выполните команды из папки проекта:

```sh
npm install
npm run dev
```

Дополнительные команды:

```sh
npm run build
npm run lint
npm run preview
```

## API

Клиент использует API Favorit Parts из задания.
